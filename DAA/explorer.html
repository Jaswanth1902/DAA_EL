Core Algorithms
1. MiniBatch K-Means
Segments color domains in spatial clusters.
O(n * k * i * d) O(n + k)
2. Canny Edge Detection
Extracts boundary profiles from color maps.
O(P) O(P)
3. Poisson-Disc Sampling
Distributes seed coordinates with distance constraints.
O(P) or O(N log N) O(N)
4. Delaunay Triangulation
Computes the optimal empty-circle coordinate mesh.
O(N log N) O(N)
5. Summed-Area Table
Computes constant-time O(1) rectangle color integrals.
O(H * W) + O(T) O(H * W)
6. WebGL/Canvas Rendering
Submits coordinates and color buffers to GPU.
O(T) O(N + T)
