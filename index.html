Algorithmic Pipeline & Architecture

Stage 1 O(K * P)

Adaptive K-Means Color Segmentation

To cluster complex color profiles, the algorithm executes unsupervised K-Means clustering. To guarantee real-time desktop execution, we downsample the input resolution to a max dimension of 512px, compute clusters, and upscale using Nearest-Neighbor Interpolation to preserve sharp, noiseless boundary edges.

Stage 2 O(P)

Feature-Aware Boundary Sampling

Canny edge detection identifies the boundaries of the clustered color segments. A 5x5 median blur pre-filter sanitizes the segmented image, removing pixel fragmentation. Points are adaptively sampled along borders (spaced by Bpointdist) and combined with randomized Poisson-disc style interior seeds to secure a balanced triangulation topology.

Stage 3 O(N log N)

Delaunay Triangulation (Empty Circle)

Triangulation is computed over the set of sampled coordinates. The algorithm satisfies the empty-circle criteria (no point is inside the circumcircle of any triangle), which maximizes the minimum interior angles of all triangles, preventing undesirable skinny or highly-skewed slivers.

Circumcircle Equation:
(x - x_c)^2 + (y - y_c)^2 = R^2
Stage 4 O(1) Optimized

Summed-Area Table (Integral Image)

Traditional color-averaging inside triangles requires drawing contour masks and running average loops, scaling as O(N * Area). We optimized this to O(1) constant time per triangle by calculating an Integral Image once, computing the rectangular area sum instantly with only four coordinate lookups.

Area Sum = I(x2,y2) + I(x1,y1) - I(x2,y1) - I(x1,y2)
